# System Info

![System Info](help/img/system-info.png?v={{VERSION}})

Here you can check the state of your device resources like the CPU and the RAM meters.

When building a pedalboard, you should pay attention to this meters in order to avoid X-runs.
X-runs will cause your audio to drop randomly.
The higher the CPU or RAM levels, more often these audio drops will happen.
