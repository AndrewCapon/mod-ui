# Pedalboard Constructor

![Pedalboard Constructor](help/img/pedalboard-constructor.png?v={{VERSION}})

This is the pedalboard Constructor, a virtual representation of the pedalboard loaded in your MOD device.
Here you can load multiple plugins/pedals, connect them between each other either via Audio, MIDI or Control Voltage and essentially set your virtual pedalboard with complete freedom and according to your needs.

**Check 
<a href="https://wiki.mod.audio/wiki/MOD_Web_GUI_User_Guide#Creating_a_New_Pedalboard" target="_blank">this page</a>
 for more info on how to create a pedalboard.**
